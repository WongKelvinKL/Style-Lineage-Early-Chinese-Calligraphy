Yan Zhenqing Calligraphy Dataset
----------
This is an image dataset of calligraphy by the renowned Tang Dynasty calligrapher Yan Zhenqing (Yan Style). This repository collects and organizes representative stele inscriptions, rubbings, and ink writings from different periods of Yan Zhenqing's career. It aims to provide high-quality reference materials for calligraphy enthusiasts, AI calligraphy recognition model training, and typeface design.

📖 Introduction

Yan Zhenqing was an outstanding calligrapher of the mid-Tang Dynasty. His regular script (Kaishu) is majestic and imposing, while his running script (Xingshu) is vigorous and powerful, exerting a profound influence on later generations. This dataset includes classic works from his early, middle, and late periods, covering both regular and running scripts.

Currently, the dataset contains 153 files in 11 folders, categorized by the title of each work.

📂 Directory Structure

All resources are named after the calligraphy works, including:

Dongfang Shuo Huazan (Portrait Eulogy of Dongfang Shuo) 

Yuan Cishan Bei (Stele of Yuan Cishan)

Duobao Ta Bei (Stele of the Multi-Treasure Pagoda)

Zhushan Tang Lianju (Linked Verses from Zhushan Hall) 

(Note: The above is only a partial list of files. Please check the repository directory for the complete content.)

🚀 Usage

1. Browse the directory

Each folder contains high-definition images or scans of the corresponding stele inscriptions. Since the images may be large, it is recommended to download them locally to view the details.

🎯 Use Cases

a) Calligraphy Learning & Copying: As reference materials for learning Yan Style regular and running scripts.

b) OCR / Computer Vision Research: For training data in ancient Chinese character recognition, calligraphy style transfer, and font generation models.

c) Typeface Design: For designers to reference the structural features of Yan Style characters.
